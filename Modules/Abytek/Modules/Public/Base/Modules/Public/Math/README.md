# Math Module

The Math module provides mathematical utilities and structures for the Abytek framework. It includes implementations for various mathematical operations essential for graphics, physics, and other computational tasks.

## Features
- Vector and matrix operations
- Quaternions and rotations
- Geometric primitives and calculations
- Interpolation methods
- Random number generation
- SIMD-optimized implementations (where available)

This module is designed to be efficient and optimized for performance-critical applications within the Abytek ecosystem.
