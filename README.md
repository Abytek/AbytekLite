# Abytek

Welcome to the Abytek project, a modular C++ framework designed for cross-platform development.

## Getting Started

New to the project? Check out our comprehensive [Getting Started Guide](Documentation/Getting%20Started.md) which provides a structured learning path for newcomers.

## Documentation

For detailed documentation on specific aspects of the project:

- [Module System Documentation](Documentation/Module%20System/Overview.md)

## Features

- **Modular Architecture**: Built around a powerful module system
- **Cross-Platform**: Supports Windows, Linux, and macOS
- **JavaScript Integration**: JavaScript-powered build tools and code generation
- **Flexible Configuration**: Advanced configuration system with fine-grained control

## Requirements

- CMake 3.15+
- C++17 compatible compiler
- Node.js 14+ (for JavaScript tools)
